Key Features

📡

USGS Landsat Integration

Automated radiometric calibration from raw Collection 2 Level-2 imagery to absolute Surface Temperature

🗺️

Geospatial Processing

Native GeoTIFF support with CRS transformations and intelligent patch-based processing

🧠

cGAN Architecture

Pix2Pix conditional GAN with U-Net generator and PatchGAN discriminator for high-quality synthesis

⚡

Multi-Loss Optimization

Combined adversarial, L1 reconstruction, and perceptual losses for enhanced visual quality

🎯

Full-Scene Inference

Sliding-window reconstruction with Gaussian blending for seamless large-scale GeoTIFF processing

🎨

Interactive Dashboard

Glassmorphic web UI with dynamic before/after split slider for visual validation
